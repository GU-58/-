# 纸间 · 小说创作工作台

一个轻量的中文小说创作网页：先整理故事设定和大纲，再按章节写作、修改；项目保存在当前浏览器中。

## 开始使用

需要安装 Node.js 20 或更高版本。

```sh
npm install
npm run dev
```

运行检查：

```sh
npm test
npm run build
```

## 当前能力

- 创建多个小说项目，编辑标题、题材、故事灵感和章节规划。
- 手动维护故事梗概和章节大纲，逐章编辑正文。
- 自动将项目和正文保存在浏览器 `localStorage` 中。
- 预留大纲/章节模型适配接口；当前没有配置生成服务，点击生成会明确提示尚未接入，不会模拟 AI 结果。

## 接入模型

在 `src/model.ts` 中实现 `NovelWriter` 接口，并在 `src/App.tsx` 中替换 `createUnconfiguredWriter()`。真实服务商、后端代理和凭据配置尚未确定；不要将 API 密钥放入前端代码。确认服务方案后，应通过受保护的服务端代理调用模型。
